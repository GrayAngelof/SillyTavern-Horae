## Инвентарь (Контейнеры)

Применяй эти правила только когда в ответе участвуют предметы, содержащие другие предметы: сумки, коробки, магазины, колчаны, гримуары и подобные составные объекты.

Контейнеры — это расширение базовых правил. Используй базовые правила для всех обычных предметов.

### Контейнер
Любой принадлежащий предмет может быть контейнером.

Контейнер содержит другие отслеживаемые предметы.

Контейнер отслеживается только если сам контейнер является предметом инвентаря.

Не создавай запись контейнера только потому, что предмет описан как находящийся внутри чего-либо.

Мебель, комнаты, местность и поверхности окружения не являются контейнерами, если только они явно не рассматриваются как принадлежащие объекты хранения.

Предмет может быть одновременно и контейнером, и содержимым предметом.

Вложенность допускается, когда цепочка размещения остаётся однозначной.

### Содержимое
Содержимое контейнера представлено отдельными записями предметов, чьё размещение ссылается на контейнер.

Цепочки размещения выражают вложенность:
item:<эмодзи><контейнер>=<владелец>@<размещение>
item:<эмодзи><содержимое>=<владелец>@in <контейнер>

Собственная запись контейнера описывает только сам контейнер.

Не кодируй его содержимое в описании.

Добавление или удаление содержимого не меняет собственную запись контейнера, за исключением составных предметов.

Выводи контейнер только когда меняется его собственное количество, владелец, размещение или значимые свойства.

Если предмет явно извлечён из контейнера, обнови размещение этого предмета.

Если предмет явно помещён в контейнер, обнови размещение этого предмета.

### Перемещение контейнера
Когда контейнер перемещается, его содержимое перемещается вместе с ним.

Не выводи содержимое только потому, что его контейнер сменил размещение.

Содержимое считается изменённым только когда:
* оно явно извлечено из контейнера;
* оно явно помещено в другой контейнер;
* его собственные свойства изменились (количество, тип, состояние);
* сам контейнер удалён из инвентаря.

### Идентичность контейнера
Контейнеры с одинаковым названием и одинаковым размещением не различаются, если только их содержимое не различается значимым образом.

Если два или более контейнера с одинаковым названием имеют одинаковое размещение и их содержимое различается, различай их нумерованным суффиксом: <контейнер>#1, <контейнер>#2.

Используй нумерованные суффиксы только когда необходимо. Не присваивай идентификаторы контейнерам, которые однозначны и без них.

### Составные предметы
Составной предмет — это контейнер, чьё содержимое определяет его идентичность.

Контейнер, содержащий один набор содержимого, отличается от контейнера с тем же названием, содержащего другой набор содержимого, даже если оба имеют одинаковое название.

Отслеживай составные предметы как контейнеры: сам составной предмет — одна запись, его содержимое — отдельные записи.

Не кодируй состав в описании составного предмета.

Для составных предметов изменения содержимого могут менять идентичность контейнера.

Отслеживай внутренний состав только когда содержимое влияет на идентичность или функциональность предмета.

Обычные контейнеры — сумки, коробки, карманы — не становятся составными предметами только потому, что что-то содержат.

### Удаление контейнера
Когда контейнер удалён из инвентаря, выводи item-: для контейнера.

Выводи item-: отдельно для каждого содержимого предмета, удалённого вместе с контейнером.

Не полагайся на неявное каскадное удаление.

Если содержимое явно извлечено до удаления контейнера, выводи обновлённое размещение для извлечённого содержимого и item-: только для контейнера.

Если содержимое не извлечено и контейнер удалён, выводи item-: для контейнера и для каждого содержимого предмета.

### Разрешение
Сначала применяй базовые правила.

Затем применяй правила, специфичные для контейнеров.

Выводи только итоговые изменения инвентаря.
