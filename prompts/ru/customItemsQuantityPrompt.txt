## Инвентарь (Контейнеры)

Применяй эти правила только тогда, когда ответ содержит предметы, которые содержат другие предметы: сумки, коробки, магазины, колчаны, гримуары и подобные составные объекты.

Контейнеры — это расширение Базовых правил. Для всех обычных предметов используй Базовые правила.

### Контейнер
Любой принадлежащий персонажу предмет может быть контейнером.

Контейнер содержит другие отслеживаемые предметы.

Контейнер отслеживается только тогда, когда сам контейнер является инвентарным предметом.

Не создавай запись контейнера только потому, что предмет описан как находящийся внутри чего-то.

Мебель, комнаты, местность и поверхности окружения не являются контейнерами, если только они явно не рассматриваются как принадлежащие персонажу объекты хранения.

Предмет может быть одновременно контейнером и содержимым.

Вложенность допускается, когда цепочка размещения остаётся однозначной.

### Содержимое
Содержимое контейнера представлено отдельными записями предметов, размещение которых ссылается на контейнер.

Цепочки размещения выражают вложенность:
item:<эмодзи><контейнер>=<владелец>@<размещение>
item:<эмодзи><содержимое>=<владелец>@в <контейнер>

Собственная запись контейнера описывает только сам контейнер.

Не кодируй его содержимое в описании.

Добавление или удаление содержимого не меняет собственную запись контейнера, за исключением составных предметов.

Выводи контейнер только тогда, когда меняется его собственное количество, владелец, размещение или значимые свойства.

Если предмет явно извлечён из контейнера, обнови размещение этого предмета.

Если предмет явно помещён в контейнер, обнови размещение этого предмета.

### Перемещение контейнера
Когда контейнер перемещается, его содержимое перемещается вместе с ним.

Не выводи содержимое лишь потому, что контейнер сменил размещение.

Содержимое считается изменившимся только тогда, когда:
* оно явно извлечено из контейнера;
* оно явно помещено в другой контейнер;
* его собственные свойства изменились (количество, тип, состояние);
* сам контейнер удалён из инвентаря.

### Идентичность контейнера
Контейнеры с одинаковым названием и одинаковым размещением не различаются, если только их содержимое не различается значимым образом.

Если два или более контейнера с одинаковым названием имеют одинаковое размещение и их содержимое различается, различай их числовым суффиксом: <контейнер>#1, <контейнер>#2.

Используй числовые суффиксы только при необходимости. Не присваивай идентификаторы контейнерам, которые однозначны без них.

### Составные предметы
Составной предмет — это контейнер, содержимое которого определяет его идентичность.

Контейнер с одним набором содержимого отличается от контейнера с тем же названием, но с другим набором содержимого, даже если оба носят одно название.

Отслеживай составные предметы как контейнеры: сам составной предмет — одна запись, его содержимое — отдельные записи.

Не кодируй состав в описании составного предмета.

Для составных предметов изменения содержимого могут менять идентичность контейнера.

Отслеживай внутренний состав только тогда, когда содержимое влияет на идентичность или функциональность предмета.

Обычные контейнеры — сумки, коробки, карманы — не становятся составными предметами лишь потому, что что-то содержат.

### Удаление контейнера
Когда контейнер удаляется из инвентаря, выведи item-: для контейнера.

Выведи item-: отдельно для каждого содержащегося предмета, который удаляется вместе с контейнером.

Не полагайся на неявное каскадное удаление.

Если содержимое явно извлечено до удаления контейнера, выведи обновлённое размещение для извлечённого содержимого и item-: только для контейнера.

Если содержимое не извлечено и контейнер удалён, выведи item-: для контейнера и для каждого содержащегося предмета.

### Разрешение
Сначала примени Базовые правила.

Затем примени правила контейнеров.

Выводи только финальные изменения инвентаря.
